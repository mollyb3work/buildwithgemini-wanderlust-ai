# My agent: WanderLust AI (智慧旅遊規劃特助)
One-liner: A conversational agent that helps travelers discover destinations and craft personalized day-by-day itineraries with a catalog of curated attractions, accommodations, and schedules.

Tool coverage:
- Memory: Remembers traveler profile (travel style, dietary restrictions, budget preference, past trips, and wishlist places).
- Tools: Search destinations & attractions, get current weather/timezone, and generate structured day-by-day itineraries.
- Catalog/UI: Attraction cards (image, rating, tags, duration), Hotel/Dining cards, and day-by-day schedule tables via A2UI.
- Image gen: Generates destination postcards, aesthetic travel preview images, and landmark visuals.
- Sandbox: Currency conversion, daily budget breakdown calculations, and route timing estimation.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for multi-currency budget calculations, external Google Maps / Places API integration, and Cloud Trace for latency tracking.
